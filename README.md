# Minecraft Takeover

**Portal 2** × Minecraft · visual · idea by the team

Bring Minecraft into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I turned a Portal 2 test chamber into Minecraft: grass blocks, creepers hissing at me, and TNT that blows the whole room apart.

## Install

Copy the mod folder's contents and the kit's game folder into a new folder named sigf next to portal2.exe, then start Portal 2 with: -game sigf -windowed +sv_cheats 1 +map sp_a2_catapult_intro. Creepers and blocks appear on their own.
